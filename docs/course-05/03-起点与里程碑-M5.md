## 建议 schema（mini 子集）

对齐官方「整数 PK + 公开字符串 id」习惯，但字段从简：

| 列 | 说明 |
|----|------|
| `id` | INTEGER PK |
| `agent_id` | TEXT UNIQUE（ULID 或短 id） |
| `user_id` | INTEGER FK → `users.id`（**归属**） |
| `name` | TEXT UNIQUE per user |
| `last_state` | TEXT（`stopped` / `running`） |
| `created_at` | INTEGER |

实现时 `user_id` 存整数 FK 即可（与官方一致）；API 只暴露 `agent_id`。

## HTTP 表面（M5 最小集）

| 方法 | 路径 | 行为 |
|------|------|------|
| GET | `/api/agents` | 当前用户的 agent 列表 |
| POST | `/api/agents` | 创建（body: `name`） |
| POST | `/api/agents/{agent_id}/start` | mock 启动 |
| POST | `/api/agents/{agent_id}/stop` | mock 停止 |

每条路由：`current_user` → 加载 agent 行 → **`_assert_agent_owner`** → 调 `AgentManager`。
