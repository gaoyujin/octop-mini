## 微课 5.5 mock 启动（⏱ 45min）

**学完能说**：单测不依赖 API key；`start` 只改状态和内存 registry。

**架子增量**：

- `AgentManager.start_agent` / `stop_agent`  
- `api/routers/agents.py` 启停路由  
- `tests/test_agents_api.py`

**先修**：5.4

### 行为（mini）

- `start`：`last_state=running`，registry 有记录，响应 `{"state":"running"}`  
- `stop`：相反；重复 start 可返回 `409` 或业务 `MiniError`（自选一种并写测）

### 验证

- [ ] 全量 `uv run pytest tests -q`，`schema_version == 4`
