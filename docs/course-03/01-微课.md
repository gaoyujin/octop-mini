## 微课 3.1 为什么要有 JWT（⏱ 30min）

**学完能说**：浏览器/客户端带 token；服务端验签后得到「当前用户」，路由用 `Depends(current_user)`。

**架子增量**：无。

**先修**：课程 02 结业

### 零基础提示

JWT = 服务端用密钥签名的声明（含 `sub` 用户名等）；**不是**把密码放在 token 里。
