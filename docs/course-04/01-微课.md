## 微课 4.1 build_app 与 lifespan（⏱ 45min）

**学完能说**：`build_app` = 注册路由 + 中间件 + 异常处理；`lifespan` 管进程内启停标记。

**架子增量**：重构 `api/app.py`（路由迁出）。

**先修**：课程 03

### 阅读（官方）

`D:\study\Octop\Octop-main\src\octop\api\app.py`：

- `build_app` 如何挂 `OctopServer`  
- 中间件注册 **顺序**（对照你 mini 里 JWT 在 include_router 前后）

### 对照 mini 今天

- `launch` 里已 `boot_control_plane` → `build_app(runtime)`  
- lifespan 里 `mark_started` / `stop` — 与官方 `OctopServer` 分工不同，属有意简化

### 验证

- [ ] 能画出：launch → build_app → middleware → router  
- [ ] `app.py` 行数明显减少（路由不在此文件内联）

## 微课 4.2 薄路由三板斧（⏱ 45min）

| `api/routers/settings.py` | 一个只读 GET |

## 微课 4.3 统一错误信封（⏱ 45min）

**学完能说**：`MiniError` 在 `infra`；`api` 注册 handler 映射 status。

**架子增量**：

- `infra/errors.py` — `ErrorCode.INVALID_CREDENTIALS` 等少量枚举  
- `api/errors.py` — `register_exception_handlers(app)`  
- 登录改 `raise MiniError(...)` 而非散落 `HTTPException`

**先修**：4.2

### 阅读（官方）

`infra/errors.py`、`api/errors.py` — 看 `OctopError` 与 handler 注册

### 响应形状（mini 建议）

```json
{ "code": "INVALID_CREDENTIALS", "message": "..." }
```

### 验证

- [ ] 错误密码 login → 401 + `code` 字段  
- [ ] pytest 断言 body 结构
