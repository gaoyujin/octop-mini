# 课程 04：起点与现状

## 课程 03 之后 mini 已有

| 能力 | 位置 | 课程 04 要改什么 |
|------|------|------------------|
| `build_app` + lifespan | `api/app.py` | 瘦身：路由迁出，只留装配 |
| JWT 中间件 | `api/middleware/jwt_auth.py` | 保持；注意注册 **顺序** |
| `auth` 路由 | `api/routers/auth.py` | 示范 **薄路由**（body 校验 → manager） |
| `deps` | `api/deps.py` | 补 `get_services`、统一异常类型 |
| `/health` 在 `app.py` 内联 | `api/app.py` | 迁到 `routers/health.py` |

**还没有**：`OctopError` 风格信封、`api/errors.py`、只读 `settings` 路由、OpenAPI tag 说明。

## 本课程增量一览

| 微课 | 实现方向 |
|------|----------|
| 4.1 | `app.py` 只做 `include_router` + `install_jwt_auth` + lifespan |
| 4.2 | `routers/health.py`、`routers/settings.py`；auth 保持薄 |
| 4.3 | `infra/errors.py` + `api/errors.py` + 全局 handler |
| 4.4 | `Depends(get_services)` 替代到处 `runtime.services` |
| 4.5 | 每个 route 有 `summary`/`tags`；可选 `openapi_tags` 元数据 |

## 与官方的刻意缩小

| 官方 | mini 课程 04 |
|------|----------------|
| Scalar `/api/docs` | FastAPI 自带 `/docs` |
| `openapi_meta.py` 大段 tag | 小型 `api/openapi_meta.py` 或 docstring |
| 几十个子 router | health + auth + settings |
| i18n 错误信封 | JSON `code` + `message` 即可 |

## 薄路由三条纪律（先背）

1. **校验在边界**：Pydantic / path 参数。  
2. **业务在 infra**：`user_manager`、repo，不在 router 写 SQL。  
3. **错误语义在 infra**：router `raise MiniError(...)`，HTTP 状态在 `api/errors.py` 映射。

## 验收总目标

- [ ] `app.py` 无业务 handler（仅装配）  
- [ ] 至少 3 个 router 模块  
- [ ] 登录失败返回统一 JSON 信封（非裸 `HTTPException` detail 字符串）  
- [ ] `GET /api/settings/bind`（或类似）只读、需登录  
- [ ] `/docs` 中每张卡片有 `summary`
