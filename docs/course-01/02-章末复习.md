# 阶段 1：配置与进程模型（章末复习）

> **日常学习**请跟 [01-微课.md](./01-微课.md)（1.1～1.6）；本文用于整章复盘与验收。

**目标**：理解 `OctopConfig`、数据目录布局、单进程组合根。  
**时长**：约 3 小时（拆成 6 节微课）

## 1.1 核心概念

- **单进程**：无独立 worker 队列（[04-ADR-单进程模型.md](./04-ADR-单进程模型.md)）。
- **OCTOP_HOME**：官方默认 `~/.octop`；本实验室建议 `MINI_HOME` 或 `~/.octop-mini`。
- **组合根**：官方 `launch.py` 启动 server + HTTP。

## 1.3 动手实验

### 实验 A：追踪 HOME（官方）

```powershell
cd D:\study\Octop\Octop-main
$env:OCTOP_HOME = "D:\tmp\octop-lab"
uv run octop init
```

确认数据库与 config 落在 `D:\tmp\octop-lab`。

### 实验 B：日志文件

运行 `octop run` 后查看 `OCTOP_HOME` 下 logs 目录，对照官方 `SizeTimedRotatingFileHandler`。

### 实验 C：画启动顺序

在 Octop-main 的 `docs\teaching\06-数据流与关键序列图.md` 图 1 上标注 **实线已读文件**。
