## 微课 6.1 Thread 是什么（⏱ 30min）

**先修**：课程 05

## 微课 6.2 从 HTTP 到 WS 路由（⏱ 45min）

**学完能说**：列表/创建用 REST；实时回合用 WebSocket。

**架子增量**：`api/routers/chat/ws.py` 注册到 `build_app`（**不被** JWT 中间件拦死 — WS 自解 token）。

**先修**：6.1

### 阅读（官方）

`api/routers/chat/ws.py` — `@router.websocket("/agents/{agent_id}/chat/ws")` 与 `token` Query。

### 对照 mini

- `deps.resolve_user_from_token(token, services)`（或从 `runtime` 取 services）
- `jwt_auth.is_jwt_exempt` **不**适用于 WS；勿把 WS 路径加进 HTTP 豁免表代替鉴权。

### 验证

- [ ] `/docs` 能看到 WebSocket 路由说明（FastAPI 展示）
