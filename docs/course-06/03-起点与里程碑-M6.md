## 建议 schema（mini 子集）

### `threads`

| 列 | 说明 |
|----|------|
| `thread_id` | TEXT UNIQUE |
| `agent_id` | FK → `agents.agent_id` |
| `user_id` | FK → `users.id` |
| `title` | TEXT（可默认「新对话」） |
| `channel_type` | TEXT，mini 固定 `dashboard` |
| `session_key` | TEXT，教学用 `dashboard:{agent_id}:{thread_id}` |
| `created_at` / `last_active` | INTEGER |

### `messages`（推荐一并做，便于 REST 历史）

| 列 | 说明 |
|----|------|
| `id` | INTEGER PK |
| `thread_id` | FK |
| `role` | `user` / `assistant` |
| `content` | TEXT |
| `created_at` | INTEGER |

可写在**同一份** `005_threads.sql` 或 `006_messages.sql`（实现时二选一，文档不锁死）。

## HTTP 表面（M6 最小集）

| 方法 | 路径 | 行为 |
|------|------|------|
| GET | `/api/agents/{agent_id}/threads` | 当前用户、该 agent 的线程列表 |
| POST | `/api/agents/{agent_id}/threads` | 创建线程（body 可选 `title`） |
| GET | `/api/agents/{agent_id}/threads/{thread_id}/messages` | 历史（JWT） |

每条：`assert_agent_owner` + 校验 `thread.agent_id` / `thread.user_id`。

## WebSocket（M6）

- 路径对齐官方：`/api/agents/{agent_id}/chat/ws`
- 鉴权：`?token=<JWT>`（**不走** HTTP JWT 中间件；参考 `resolve_user_from_token`）
- 入站帧（mini 简化）：

```json
{ "type": "user_turn", "thread_id": "…", "text": "hello" }
```

- 出站（echo）：

```json
{ "type": "assistant_text", "text": "echo: hello" }
{ "type": "done" }
```

- 可选：agent **须 running** 才接受 WS（练业务规则）；或仅校验归属 — 实现时选一种并写测。
