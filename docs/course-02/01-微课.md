**架子增量**：mini **迁移 v2** + `users` 表。

**先修**：2.2

### 阅读

## 微课 2.4 Repo 与 SharedServices（⏱ 60min）

**学完能说**：HTTP 层不写 SQL；`SharedServices.user_repo` 访问数据。

**架子增量**：`UserRepo` + 扩展 `build_shared_services`。

**先修**：2.3

### 阅读

| 官方 | mini 目标 |
|------|-----------|
| `infra/db/services.py` | 扩展 `SharedServices` 字段 |
| `infra/db/repos/users.py` | 简版 `get_by_username` / `create` |

- `infra/db/repos/*` **只** import `pool`、同包 `_base`（若有）；不 import `api`。
